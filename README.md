# 🌍 Web-Tour-Du-Lich

Website đặt tour du lịch trực tuyến giúp người dùng dễ dàng tìm kiếm địa điểm, khám phá các tour hấp dẫn và đặt tour nhanh chóng với giao diện hiện đại, thân thiện.

---

## 📌 Giới thiệu

**Web-Tour-Du-Lich** được xây dựng nhằm mang đến trải nghiệm du lịch tiện lợi cho người dùng. Hệ thống hỗ trợ xem thông tin tour, tìm kiếm điểm đến yêu thích, đặt tour online và quản lý lịch sử đặt tour.

Website phù hợp cho các công ty du lịch muốn quảng bá dịch vụ và hỗ trợ khách hàng đặt tour nhanh chóng.

---

## ✨ Chức năng chính

- 🏠 Trang chủ giới thiệu tour nổi bật
- 🔍 Tìm kiếm địa điểm du lịch
- 🌄 Khám phá các tour hấp dẫn
- 📝 Đặt tour trực tuyến
- 👤 Quản lý thông tin người dùng
- 📅 Xem lịch sử đặt tour
- 📞 Trang hỗ trợ khách hàng
- 🎵 Tích hợp nhạc nền website

## 🚀 Cách chạy project

### Cách 1: Live Server (VS Code)

1. Mở project bằng VS Code  
2. Cài extension **Live Server**  
3. Chuột phải file `trangChu.html`  
4. Chọn **Open with Live Server**
